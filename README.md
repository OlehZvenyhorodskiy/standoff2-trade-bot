# Standoff 2 Market Sniper

Python-проект для калибруемой GUI-автоматизации через Android-эмулятор. Захват экрана сделан через `mss`, анализ — через `OpenCV`, клики — через `pydirectinput` с fallback на `pyautogui`.

По умолчанию включен `dry_run: true`, поэтому основной цикл не нажимает покупку, пока вы явно не поменяете это в `standoff_sniper/config.json`.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

OCR через `pytesseract` опционален. Если включаете `budget.enabled`, установите Tesseract OCR отдельно и проверьте, что `pytesseract` видит бинарник `tesseract.exe`.

## Подготовка шаблонов

1. Откройте Standoff 2 в эмуляторе в том же размере окна, в котором будет работать скрипт.
2. Сделайте скриншот рынка.
3. В любом редакторе вырежьте маленький фрагмент одной желтой/золотой иконки наклейки. Сохраните как `standoff_sniper/templates/sticker.png`.
4. Откройте окно подтверждения покупки и вырежьте стабильный фрагмент кнопки «Купить». Сохраните как `standoff_sniper/templates/buy_button.png`.

Важно: если меняете масштаб Windows, DPI, размер окна эмулятора или графические настройки, шаблоны и калибровку лучше сделать заново.

## Калибровка

```powershell
python standoff_sniper/calibrator.py
```

Калибратор попросит навести курсор и нажать Enter в консоли для:

- кнопки/чекбокса «Только с наклейками»;
- центра первого лота;
- центра кнопки «Купить»;
- области первого лота для поиска наклеек;
- области появления кнопки покупки;
- области цены, если включаете OCR бюджета.

Во время калибровки не кликайте по эмулятору. Просто наведите курсор поверх нужного места, оставляя фокус на консоли, и нажмите Enter.

## Запуск

Сначала проверьте один цикл без реальной покупки:

```powershell
python standoff_sniper/main.py --once
```

Для непрерывного режима:

```powershell
python standoff_sniper/main.py
```

Горячие клавиши по умолчанию:

- `Esc` — остановить;
- `F4` — пауза/продолжить.

Чтобы разрешить реальные клики покупки, поменяйте в `standoff_sniper/config.json`:

```json
"dry_run": false
```

## Настройки OpenCV

Главные параметры находятся в `vision`:

- `min_stickers` — минимальное количество наклеек для покупки, обычно `3` или `4`;
- `sticker_threshold` — порог совпадения шаблона наклейки;
- `buy_button_threshold` — порог совпадения шаблона кнопки покупки;
- `sticker_min_distance_px` — минимальная дистанция между найденными наклейками, чтобы не считать один значок несколько раз.

Если бот не видит наклейки, немного снижайте `sticker_threshold`, например с `0.84` до `0.78`. Если появляются ложные срабатывания — повышайте.

## Проверка окна эмулятора

В `config.json` есть опция:

```json
"emulator": {
  "check_window": false
}
```

Если поставить `true`, скрипт перед стартом попробует найти окно по `window_title_keywords`. Если окно не найдено, запуск остановится с ошибкой.

## Бюджет и OCR

OCR замедляет цикл. Включайте его только если фильтра рынка недостаточно:

```json
"budget": {
  "enabled": true,
  "max_price": 2.46
}
```

После включения OCR повторно запустите калибратор и задайте область цены.

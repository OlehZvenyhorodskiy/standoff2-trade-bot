# Шаблоны OpenCV

Положите сюда:

- `sticker.png` — маленький crop одной наклейки/иконки наклейки из первого лота.
- `buy_button.png` — crop стабильной части кнопки «Купить» в окне подтверждения.

Шаблоны должны быть сделаны при том же масштабе эмулятора и том же разрешении, в котором будет работать бот.
